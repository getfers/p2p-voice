# Эфир

Десктопные голосовые комнаты и чат без учётных записей и центрального сервера приложения. Хост создаёт комнату на своём компьютере и ретранслирует зашифрованные пакеты между участниками. В комнате может быть до восьми человек, включая хоста.

## Запуск

Понадобится Python 3.11 или новее. На Linux установите PortAudio и библиотеки для Qt/X11 через пакетный менеджер. В Debian и Ubuntu это `libportaudio2`, `libxcb-cursor0` и `libxkbcommon-x11-0`. На macOS и Windows разрешите приложению использовать микрофон в настройках ОС.

**Windows, PowerShell**

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -B main.py
```

**Linux и macOS**

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -B main.py
```

## Создание комнаты и подключение

1. Хост и гость выбирают одинаковый режим. Хост создаёт комнату и нажимает «Создать приглашение».
2. Хост вручную передаёт гостю токен и 256-битный ключ приглашения по двум раздельным доверенным каналам. Приглашение действует 10 минут и принимается один раз. Для каждого гостя создаётся новое.
3. Гость нажимает «Подключиться по токену» и вводит оба значения. При WebRTC он передаёт получившийся зашифрованный ответ хосту. Хост вставляет его и нажимает «Принять ответ». В режиме SOCKS5 ответ передаётся в самом туннеле.
4. Каждый участник нажимает **SAS** рядом с позывным собеседника и сверяет шестизначный код голосом по доверенному каналу, например обычным телефонным звонком. Оба нажимают «Коды совпали». Аудио и чат открываются для этой пары после двух подтверждений.
5. Микрофон по умолчанию выключен. Для Push-to-Talk включите микрофон и удерживайте F8 в активном приложении или кнопку «Говорить». Зелёная рамка показывает уровень голоса. Шумовой порог приглушает тихий фон в паузах. Настройка входа и выхода находится внизу комнаты.

### Сетевые режимы

| Режим | Когда подходит | Что видно в сети |
| --- | --- | --- |
| Строгий, прямой IP | Локальная сеть, частная сеть или доступный UDP-порт | Используются числовые ICE-адреса. Собеседники видят IP друг друга. |
| STUN | Прямой вызов из разных сетей при совместимом NAT | Публичный STUN Google получает запрос для определения внешнего адреса. Аудио и чат идут между участниками. |
| Строгий, SOCKS5 / Tor | Подключение через локальный прокси и доступный TCP-мост или onion-сервис хоста | TCP-адрес передаётся локальному SOCKS5. Для onion-сервиса Tor скрывает сетевые адреса участников друг от друга. |

Для прямого вызова в одной сети поле внешнего адреса можно оставить пустым. При ручном пробросе UDP укажите внешний `IP:порт` до выпуска токена, затем направьте этот порт на локальный адрес ICE, показанный под приглашением. При нескольких интерфейсах используйте первый подходящий адрес. Для IPv6 используйте формат `[адрес]:порт`. При CGNAT, симметричном NAT или блокировке UDP может понадобиться SOCKS5.

Для режима Tor запустите Tor на обеих машинах. Хост создаёт onion-сервис, который направляет TCP на локальный порт приложения. Пример настроек хоста в `torrc`:

```text
HiddenServiceDir /path/to/efir-onion
HiddenServicePort 17840 127.0.0.1:17840
```

На Windows замените путь на абсолютный локальный путь, доступный Tor. После запуска Tor скопируйте адрес из файла `hostname` и укажите его в комнате хоста в виде `<адрес>.onion:17840`. Гость указывает локальный SOCKS5, например `127.0.0.1:9050`. Хост слушает только `127.0.0.1`. Приложение использует только SOCKS5 CONNECT к хосту через локальный прокси и передаёт имя прокси без локального DNS. TCP через Tor может заметно увеличить задержку голоса. Каталог onion-сервиса и его ключи обслуживает Tor. [Настройка onion-сервиса](https://community.torproject.org/onion-services/setup/)

## Шифрование и хранение данных

- В режимах WebRTC описание SDP сжимается и шифруется ChaCha20-Poly1305 отдельным ключом приглашения. Надёжный DataChannel передаёт чат, ненадёжный неупорядоченный канал передаёт 20-мс PCM-фреймы. DataChannel использует SCTP поверх DTLS. SRTP применяется к штатным RTP-медиатрекам WebRTC. Режим SOCKS5 использует свой шифрованный транспорт поверх TCP.
- Для каждого соединения X25519, HKDF-SHA256 и ChaCha20-Poly1305 защищают транспорт приложения. Для аудио и чата каждая пара участников дополнительно выводит отдельные ключи. Хост видит состав комнаты, отправителей, получателей, размеры и время пакетов. При ретрансляции содержимое между двумя гостями остаётся зашифрованным.
- Для SAS обе стороны фиксируют случайный вклад до его раскрытия. Подтверждение действует для конкретной пары ключей до выхода из комнаты. После подтверждения хост может читать сообщения, адресованные ему как участнику, и слышать переданное ему аудио.
- Позывной и первая временная пара X25519 создаются при запуске. Для каждой следующей комнаты используется новая пара. Приложение хранит звонок и чат в памяти, без базы данных и журналов. При выходе закрываются соединения, очищаются виджеты и очереди, перезаписываются доступные изменяемые буферы и освобождаются объекты ключей. Python, Qt, драйверы, файл подкачки, дампы и история системного буфера обмена находятся вне контроля приложения.

## Проверка и сборка Windows

```powershell
$python = '.\.venv\Scripts\python.exe'
& $python -B -m unittest discover -s tests -v
& $python -B main.py --self-test
$savedPath = $env:Path
try {
    $env:Path = "$env:SystemRoot\System32;$env:SystemRoot"
    & $python -m PyInstaller --noconfirm --clean --noupx --onefile --windowed --name Efir --collect-all av --recursive-copy-metadata aiortc --recursive-copy-metadata PyQt6 --recursive-copy-metadata sounddevice main.py
} finally {
    $env:Path = $savedPath
}
```

Готовый файл находится в `dist/Efir.exe`. PyInstaller распаковывает библиотеки однофайловой сборки во временный каталог при запуске. GitHub Actions после каждого пуша в `main` проверяет запуск, собирает Windows x64 и публикует `Efir.exe` вместе с SHA-256 на странице [Releases](https://github.com/getfers/p2p-voice/releases). Для сборки с собственными библиотеками Qt используйте исходники и команду PyInstaller выше. Пакет PyQt6 можно собрать с выбранной версией Qt по официальным инструкциям.
